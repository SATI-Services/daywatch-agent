Leave a teammate context in `notes/` as one file per message, named `YYYY-MM-DD-<from>-to-<to>-<slug>.md`.

**Why:** `notes/` is the inter-author inbox; the name carries the date and the from→to pair so each message is a discrete, addressable handoff.
