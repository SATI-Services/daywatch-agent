Inter-author messages in `docs/sessions/notes/` are files named `YYYY-MM-DD-<from>-to-<to>-<slug>.md`, one file per message. A teammate leaves you context by dropping a note addressed to you — they cannot edit your status file.

**Why:** One dated, addressed file per message keeps each handoff individually trackable as an inbox item across the write-partition.
